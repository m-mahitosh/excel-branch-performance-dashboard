📊 Branch Performance MIS Dashboard
Project Overview
This project demonstrates the development of an interactive Branch Performance MIS Dashboard using Microsoft Excel.

The dashboard converts raw sales data into meaningful business insights using Pivot Tables, Pivot Charts, KPI Cards, and interactive analysis.

Key Metrics
Total Sales
Total Customers
Average Ticket Size
Target Achievement %
Top Performing Branch
Analysis Performed
Region Wise Sales
Analyzed sales performance across East, West, North, and South regions.

Product Wise Contribution
Measured contribution of each product category.

Monthly Trend Analysis
Tracked monthly sales growth and trends.

Branch Performance
Identified top-performing branches.

RM Performance
Compared sales performance against targets.
